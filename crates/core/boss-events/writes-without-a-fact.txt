# writes-without-a-fact.txt — the ONE allowlist of
# crates/core/boss-testing/tests/every_write_stages_a_fact.rs
# (backlog 8c271e8f, design 3036296f mechanism A, David approved
# 2026-09-27).
#
# The rule: every Postgres write in non-test code stages its fact on the
# outbox in the same transaction (boss_events::outbox::record_event_in_tx)
# — the log is the system of record. A write that does not is named here,
# with its reason, or the pin fails naming it.
#
# FORMAT, one entry per line:
#
#   <status> <scope> <target> -- <reason>
#
#   status  not-a-fact  the write is not a state change of the company:
#                       a projection rebuilt from the log, a cache, a
#                       session, telemetry (David 2026-09-16: "the
#                       audit_log just needs to capture all work that is
#                       done; sensors record data that don't flow into
#                       the audit_log"), outbox bookkeeping.
#           gap         the write IS a state change and stages nothing.
#                       Measured when the pin landed and recorded so the
#                       tree stays green while each is retired by its own
#                       car — a DEBT, never a decision that the write
#                       needs no fact. Retiring one means staging the
#                       fact and deleting the line; the pin then refuses
#                       the line as stale until it goes.
#   scope   fn <file>::<Type::fn | fn>   one function and every write in it
#           file <file>                  every function in one file (a
#                                        rebuilder module)
#           table <name>                 every write to one table
#
# An entry that excuses a function also covers the transaction helpers
# it drives (a rebuilder's `upsert_row(&mut conn, ..)`), which is why a
# helper shared by a live path and a rebuilder needs no entry of its own
# once the rebuilder has one. Every entry must still excuse something:
# a stale allowance is a hole shaped like a write that no longer exists.
#
# Adding a line here is a decision a reviewer should see. A new write
# that is a fact does not go here: it stages its event.
